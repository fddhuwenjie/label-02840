# 鲜果蔬园 - 蔬果购物H5电商网站

一个基于 Vue 3 的移动端蔬果购物电商网站，采用清新明快的配色风格，提供完整的购物体验。

## How to Run

### Docker 启动（推荐）

```bash
# 构建并启动服务
docker-compose up --build -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f frontend

# 停止服务
docker-compose down
```

启动后访问：http://localhost:8081

### 本地启动

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 开发模式启动
npm run dev

# 生产构建
npm run build

# 预览生产构建
npm run preview
```

开发模式访问：http://localhost:8081

## 题目内容

### 项目要求

1项目为手机电商客户端项目，平台为H5，整体布局为纵向移动项目布局。 
2内容可以借鉴网上成熟的电商平台H5网站、微信小程序、App端的布局。 
3网站整体配色明快清新，不要采用过于跳跃的配色。   
4项目需使用Vue.js框架以SPA（单页应用模式）进行开发，项目中可使用mui、Element-UI、Bootstrap等第三方UI框架。 
5项目构建方式可以自行搭建项目结构，也可以利用vue CLI工具构建脚手架项目。5项目中用到的资源素材自行设计。   
6项目中至少应包含登陆、注册、商品详情、首页（含推荐列表）、购物车等组件，必须使用官方插件router和Vue.实现组件切换和数据状态管理，功能不设上线越丰富分数越高。请根据以上要求 做一个蔬果购物网站 用中文与我对话

### 功能模块

- ✅ 登录页面 - 用户登录功能
- ✅ 注册页面 - 新用户注册功能
- ✅ 首页 - 轮播图、分类入口、限时特惠、热销推荐
- ✅ 分类页面 - 商品分类浏览
- ✅ 商品详情页 - 商品信息展示、加入购物车、立即购买
- ✅ 搜索页面 - 关键词搜索、搜索历史、热门搜索
- ✅ 购物车页面 - 商品管理、数量修改、结算
- ✅ 确认订单页 - 地址选择、订单提交
- ✅ 订单列表页 - 订单状态查看
- ✅ 收货地址管理 - 地址增删改查
- ✅ 个人中心 - 用户信息、订单入口、功能菜单

### 技术栈

- **前端框架**: Vue 3 (Composition API)
- **路由管理**: Vue Router 4
- **状态管理**: Pinia
- **UI 组件库**: Vant 4
- **构建工具**: Vite 5
- **CSS 预处理**: Sass
- **容器化**: Docker + Nginx

### 项目特点

1. 采用 Vue 3 Composition API，代码更简洁
2. 使用 Pinia 进行状态管理，支持数据持久化
3. 响应式移动端布局，适配各种屏幕尺寸
4. 清新绿色主题配色，视觉体验舒适
5. 完整的购物流程，从浏览到下单
6. Docker 容器化部署，一键启动
7. 中文代码注释，便于学习理解
